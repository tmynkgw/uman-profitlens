# アサイン登録機能仕様

> **根拠ソース**: [src/app/page.tsx](../../src/app/page.tsx)（`aForm`, `saveAlloc`, `deleteAlloc`, `openAddAlloc`, `openEditAlloc`）

---

## 1. 概要

> ID: EN-001

要員をプロジェクトに月単位で工数配分（GL-001 アサイン）する **CRUDメインのタブ** です。
選択年度に属するアサインデータのみ一覧表示します。

---

## 2. 一覧表示

> ID: EN-010

### 表示カラム

| ID | カラム | 内容 | 備考 |
|----|-------|------|------|
| EN-011 | PJ名 | アサイン先プロジェクト名 | |
| EN-012 | 要員名 | 姓 + 名（スペース区切り） | |
| EN-013 | 部門 | 要員の所属部門（カラーバッジ） | COMP-002 `DeptBadge` コンポーネント |
| EN-014 | ロール | 要員の役職名 | |
| EN-015 | 月 | アサイン対象月（YYYY-MM形式） | |
| EN-016 | 時間 | 稼働時間（GL-002 工数、単位: h） | |
| EN-017 | 単価 | GL-003 コスト単価（円/時間） | |
| EN-018 | 月間コスト | `hours × cost_rate`（GL-004 コスト、円、自動計算） | |
| EN-019 | 操作 | 編集・削除ボタン | |

### ソート

- **[EN-020]** ソート条件: 月の **降順**（新しい月が上に来る）

---

## 3. 新規アサイン登録（モーダル）

> ID: EN-030

右上の「追加」ボタンをクリックするとモーダルが開きます。

### 入力項目

| ID | 項目 | 入力形式 | 必須 | デフォルト値 | 備考 |
|----|-----|---------|------|------------|------|
| EN-031 | プロジェクト | 選択リスト（全プロジェクト） | ○ | 最初のPJ | 未選択の場合は保存不可 |
| EN-032 | 要員 | 選択リスト（全要員） | ○ | 最初の要員 | 未選択の場合は保存不可 |
| EN-033 | 月 | 月入力（YYYY-MM） | ○ | `2025-06` | |
| EN-034 | 稼働時間 | 数値入力（時間） | ○ | `160` | |
| EN-035 | コスト単価 | 数値入力（円/h） | ○ | `5000` | |

### リアルタイムプレビュー

- **[EN-036]** 「月間コスト = 稼働時間 × コスト単価」をリアルタイムで表示

### バリデーション

- **[EN-037]** プロジェクトID・要員IDが空の場合は保存ボタンが機能しない（保存処理が即座に終了）

> ※推測（要確認）: 同一プロジェクト × 同一要員 × 同一月の **重複登録を防ぐバリデーションは現在未実装** です。これが意図的な設計（複数アサインを許容）なのか、将来対応予定なのかは不明です。

---

## 4. アサイン編集（モーダル）

> ID: EN-040

各行の編集ボタンをクリックすると、既存の値がフォームに入力された状態でモーダルが開きます。
全フィールドを再入力できます。

---

## 5. アサイン削除

> ID: EN-050

各行の削除ボタンをクリックすると確認ダイアログが表示されます。

- **[EN-051]** 確認後: アサインを削除
- **[EN-052]** 連鎖削除: なし（アサイン単体の削除のみ）
- **[EN-053]** フィードバック: 削除完了のトースト通知を表示

---

## 6. 自動保存の仕組み

> ID: EN-060

アサインの追加・編集・削除を行うと、Reactのstate変更が発生します。
stateが変化すると自動的に `saveData()` が実行され、Supabase上のデータが更新されます。

詳細は[データフロー設計](../04_architecture/data_flow.md)を参照してください。
