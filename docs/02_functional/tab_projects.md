# プロジェクト管理機能仕様

> **根拠ソース**: [src/app/page.tsx](../../src/app/page.tsx)（`pForm`, `saveProject`, `deleteProject`, `projectPL` useMemo）

---

## 1. 概要

> ID: PJ-001

プロジェクトのCRUDと、プロジェクトごとの **四半期財務分析** を行うタブです。

---

## 2. プロジェクト一覧（カードレイアウト）

> ID: PJ-010

各プロジェクトがカード形式で表示されます。

### カード内の表示要素

| ID | 要素 | 内容 |
|----|-----|------|
| PJ-011 | プロジェクト名 | 登録名称 |
| PJ-012 | ステータスバッジ | GL-014 予定 / GL-015 進行中 / GL-016 完了（色分け） |
| PJ-013 | クライアント名 | 顧客名 |
| PJ-014 | 期間 | 開始月〜終了月 |
| PJ-015 | 配置要員 | プロジェクトに登録された要員の姓名一覧 |
| PJ-016 | 四半期グラフ | Q1〜Q4（RULE-QTR-001〜004）の予算/コスト/利益の棒グラフ（COMP-005） |
| PJ-017 | 四半期サマリーグリッド | Q1〜Q4 × 予算・コスト・利益・利益率の数値表 |
| PJ-018 | 年間フッター | 年間予算合計・年間コスト合計・年間利益・利益率 |
| PJ-019 | 操作ボタン | 編集・削除 |

### ステータスの色分け（GL-014〜016 参照）

| ID | ステータス | 表示色 |
|----|-----------|--------|
| GL-014 | **予定** | 黄（Amber） |
| GL-015 | **進行中** | 緑（Emerald） |
| GL-016 | **完了** | グレー（Slate） |

---

## 3. プロジェクト登録・編集（モーダル）

> ID: PJ-020

右上の「追加」ボタン、または各カードの編集ボタンでモーダルが開きます。
モーダルサイズは通常より広い（Wide）表示です。

### 入力項目

| ID | 項目 | 入力形式 | 必須 | 初期値 | 備考 |
|----|-----|---------|------|-------|------|
| PJ-021 | プロジェクト名 | テキスト | ○ | 空 | 空文字は保存不可 |
| PJ-022 | クライアント名 | テキスト | - | 空 | |
| PJ-023 | ステータス | 選択リスト（予定/進行中/完了） | ○ | `予定` | |
| PJ-024 | 開始月 | 月入力（YYYY-MM） | - | 空 | |
| PJ-025 | 終了月 | 月入力（YYYY-MM） | - | 空 | |
| PJ-026 | 配置要員 | 複数選択チェックボックス | - | なし | 全要員を部門バッジ・ロール名付きで一覧表示 |
| PJ-027 | 四半期別売上予算 | 数値入力（万円）× 4 | - | 0 | Q1〜Q4の入力欄。年間合計をリアルタイム表示 |

### 入力補助

- **[PJ-028]** 要員選択欄の下に選択済み要員数を表示
- **[PJ-029]** 四半期予算欄の下に年間合計をリアルタイム計算・表示

---

## 4. プロジェクト削除

> ID: PJ-030

### 削除ダイアログ

- **[PJ-031]** 削除前に確認ダイアログを表示
- **[PJ-032]** ダイアログに警告メッセージを表示

### 連鎖削除ルール

| ID | 削除対象 | 連鎖削除される対象 |
|----|---------|-----------------|
| PJ-033 | プロジェクト | 当プロジェクトに紐づく全アサイン |

---

## 5. 財務分析の算出ロジック

> ID: PJ-040

プロジェクトカードの財務データは選択年度に基づいて動的に計算されます。

| ID | 指標 | 算出式 |
|----|-----|-------|
| RULE-KPI-001 | 四半期予算 | `quarter_budgets["FY2025-Q1"] × 10000`（万円→円） |
| RULE-KPI-002 | 四半期コスト | 当四半期の月に属するアサインの `Σ(hours × cost_rate)` |
| RULE-KPI-003 | 四半期利益 | 四半期予算 − 四半期コスト |
| RULE-KPI-004 | 年間予算 | Q1〜Q4の四半期予算合計 |
| RULE-KPI-007 | 利益率 | `利益 / 年間予算 × 100`（予算0の場合は0%） |
