# 要員DB機能仕様

> **根拠ソース**: [src/app/page.tsx](../../src/app/page.tsx)（`mForm`, `saveMember`, `deleteMember`, `memberStats` useMemo）

---

## 1. 概要

> ID: MB-001

コンサルタント（要員）のマスタ管理と、年度別の予算達成率を可視化するタブです。

---

## 2. 一覧表示（テーブル形式）

> ID: MB-010

### 表示カラム

| ID | カラム | 内容 | 備考 |
|----|-------|------|------|
| MB-011 | ID | 要員ID（M001形式、GL-019 参照） | |
| MB-012 | 姓 | 姓（lastName） | |
| MB-013 | 名 | 名（firstName） | |
| MB-014 | ロール | 役職名 | |
| MB-015 | 部門 | 所属部門（カラーバッジ） | COMP-002 `DeptBadge` コンポーネント |
| MB-016 | 年度目標 | 選択年度の年度予算（万円）（GL-006 参照） | `yearly_budgets[selectedFY]` |
| MB-017 | 売上実績 | 選択年度のアサインコスト合計（RULE-KPI-008） | `Σ(hours × cost_rate)` |
| MB-018 | 達成率 | 実績 ÷ 目標 × 100（%）（リング表示）（GL-007 参照） | 目標未設定時は「―」※推測（要確認）参照 |
| MB-019 | PJ数 | 選択年度の参加プロジェクト数（RULE-KPI-011） | 重複なし |
| MB-020 | 操作 | 編集・削除ボタン | |

### ソート

- **[MB-021]** ソート条件: 達成率の **降順**（達成率が高い要員が上に表示される）

> ※推測（要確認）: 年度予算が0（未設定）の場合、達成率が0%となり「―」表示になるか、または0%として扱われるかは実装上の挙動確認が必要です。

---

## 3. 要員登録・編集（モーダル）

> ID: MB-030

右上の「追加」ボタン、または各行の編集ボタンでモーダルが開きます。

### 入力項目

| ID | 項目 | 入力形式 | 必須 | 初期値 | 備考 |
|----|-----|---------|------|-------|------|
| MB-031 | 姓 | テキスト | ○ | 空 | 空文字は保存不可 |
| MB-032 | 名 | テキスト | - | 空 | 2カラムグリッドで姓と横並び |
| MB-033 | ロール | 選択リスト | - | 最初のロール | |
| MB-034 | 部門 | 選択リスト | - | 最初の部門 | |
| MB-035 | 開始月 | 月入力（YYYY-MM） | - | `2025-01` | 参画開始月（入社月等） |
| MB-036 | 年度別目標予算 | 数値入力（万円）× 年度数 | - | 各0 | 利用可能年度ごとに入力欄を動的生成 |

### 年度別目標予算の入力欄

- **[MB-037]** アサインデータや四半期予算に存在する全年度分の入力欄を動的生成
- **[MB-038]** 利用可能年度が0件の場合は「アサインを登録すると年度が表示されます」とメッセージ表示

---

## 4. 要員削除

> ID: MB-040

### 削除ダイアログ

削除前に確認ダイアログを表示します。

### 連鎖削除ルール

| ID | 削除対象 | 連鎖削除・変更される対象 |
|----|---------|----------------------|
| MB-041 | 要員 | 当要員の全アサインを削除 |
| MB-042 | 要員 | 全プロジェクトの `memberIds` から当要員IDを除外 |

---

## 5. 達成率リングの色分け（RULE-COLOR-001〜003 参照）

| ID | 達成率 | 表示色 |
|----|-------|--------|
| RULE-COLOR-001 | 100%以上 | 緑（Emerald） |
| RULE-COLOR-002 | 70%以上100%未満 | 黄（Amber） |
| RULE-COLOR-003 | 70%未満 | 赤（Red） |
