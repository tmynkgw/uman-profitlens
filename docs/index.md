# ProfitLens ドキュメント

**ProfitLens** はコンサルティング事業向けの **プロジェクト収益管理システム** です。
プロジェクト・要員・アサイン（工数配分）データを一元管理し、年度・四半期単位の収益をダッシュボードで可視化します。

> このドキュメント群はソースコードから **リバースエンジニアリング** により生成されました。
> ソースコードから確実に読み取れる仕様と、推測される内容は **「※推測（要確認）」** と明示して区別しています。

## システム構成の概要

```
ブラウザ（React SPA）
     │
     │ Supabase REST API（@supabase/supabase-js）
     │
     ▼
Supabase（PostgreSQL）
  ├── departments（部門）
  ├── roles（役職）
  ├── members（要員）
  ├── projects（プロジェクト）
  └── allocations（アサイン）
```

## ドキュメント管理方針

| 方針 | 内容 |
|-----|------|
| 事実と推測の分離 | ソースコードから確実に読み取れる仕様はそのまま記載。確認が必要な内容は「**※推測（要確認）**」と明記 |
| 変更頻度による分割 | 変更頻度の低い仕様（DBスキーマ・業務ルール）と高い仕様（運用手順・機能仕様）を別ファイルに分離 |
| 可読性の優先 | コードレベルの詳細より、ビジネスサイドの人間にも理解できる抽象度を優先 |
| Gitでの差分管理 | 機能タブごと・エンティティごとにファイルを分割し、変更が局所化されるよう設計 |
