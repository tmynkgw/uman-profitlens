# ProfitLens システム概要

## 1. システムの目的

**ProfitLens** は、コンサルティング事業を行う組織向けのプロジェクト収益管理Webシステムです。

プロジェクトへの要員アサイン（工数配分）を記録することで、以下を一元管理します。

- プロジェクト別の **売上予算・コスト・利益** の可視化
- 要員ごとの **年度予算達成率** のモニタリング
- 四半期・年度単位での **収益分析**

---

## 2. 適用範囲（スコープ）

### 対象業務

| ID | 業務カテゴリ | 内容 |
|----|-------------|------|
| OV-001 | マスタ管理 | 部門・役職・要員の登録・更新・削除 |
| OV-002 | プロジェクト管理 | プロジェクトの登録・四半期別売上予算の設定 |
| OV-003 | アサイン管理 | 月単位の工数（時間数・コスト単価）の記録 |
| OV-004 | 収益分析 | KPI表示・グラフ・ランキングによるダッシュボード表示 |
| OV-005 | データ管理 | JSONファイルのエクスポート・インポート |

### 対象外業務（現時点）

> ※推測（要確認）: 以下は現在実装されていない機能です。将来の追加計画は未定です。

- 請求書の作成・発行
- 外部会計システム（勘定奉行等）との連携
- 給与計算・経費精算
- 稟議・承認ワークフロー

## 3. ビジネスアクター

> ※推測（要確認）: 本システムは現在認証機能が未実装であり、URLを知る全員が全操作を実行できます。以下のアクター区分は、将来の認証実装時を想定した推測です。

| ID | アクター | 想定業務 | 利用機能 |
|----|---------|---------|---------|
| OV-010 | **パートナー / 上位職** | 組織全体の収益状況の把握・経営判断 | ダッシュボード（KPI・グラフ・ランキング）の参照 |
| OV-011 | **マネージャー** | プロジェクトの管理・要員アサインの登録・予算設定 | 全タブの操作（プロジェクト・アサイン・要員・部門・役職） |
| OV-012 | **管理担当者** | 部門・役職マスタの維持管理 | 部門DB・ロールDB・要員DBの操作 |

### 現在の権限状態（確認済み事実）

- **認証なし**: 全ユーザーが全データの読み書き・削除を実行できる
- **Row Level Security**: 有効化されているが、全ユーザーに全操作を許可するポリシーが適用されている
- **DEMO/本番の切り替え**: 環境変数 `NEXT_PUBLIC_IS_DEMO`（ENV-003）による表示変更のみ（機能制限なし）

## 4. システムが解決する業務課題

> ※推測（要確認）: ソースコードには課題の記述がないため、機能から推測した内容です。

| ID | 課題 | ProfitLensによる解決策 |
|----|-----|---------------------|
| OV-020 | スプレッドシートで管理していたプロジェクト収益情報が散在している | Webシステムで一元管理し、複数人が同一データを参照できる |
| OV-021 | プロジェクトの実際のコストがリアルタイムで把握できない | アサイン入力のたびに自動集計・即時反映される |
| OV-022 | 要員ごとの予算達成状況が見えにくい | 達成率リングと年度比較グラフで直感的に把握できる |
| OV-023 | データのバックアップや引き継ぎが困難 | JSONファイルでのエクスポート・インポートをサポート |

## 5. DEMO版と本番版の区別

| ID | 項目 | DEMO版（`ENV-003=true`） | 本番版（`ENV-003=false`） |
|----|-----|--------------------------|--------------------------|
| OV-030 | ロゴ横のバッジ | 「DEMO」バッジ（オレンジ）が表示される | 表示なし |
| OV-031 | 警告バナー | 「これはデモ版です」バナーが表示される | 表示なし |
| OV-032 | データの保存先 | Supabase（実際にデータが保存される） | Supabase（同じ） |
| OV-033 | 機能制限 | なし（全CRUD操作が可能） | なし（同じ） |
