# 会計年度・KPI算出ルール

本ドキュメントは ProfitLens における会計年度の定義と、各KPIの算出ロジックを定義します。

> **根拠ソース**: [src/lib/data.ts](../../src/lib/data.ts)（`monthToFY`, `monthToFYQ`, `fyMonths`, `fyQMonths` 関数）

---

## 1. 会計年度（FY）の定義

### 基本ルール

- **[FY-001]** 開始月: **4月**
- **[FY-002]** 終了月: **翌年3月**
- **[FY-003]** FY番号: 開始年の西暦年を使用（例: 2025年4月〜2026年3月 = `FY2025`）

### 月 → 会計年度の変換ルール

| ID | 月 | 変換ルール | 例 |
|----|----|-----------|-----|
| RULE-FY-001 | 4月〜12月 | `FY{当年}` | 2025年7月 → `FY2025` |
| RULE-FY-002 | 1月〜3月 | `FY{前年}` | 2026年1月 → `FY2025` |

### 具体例

| 月 | 会計年度 |
|----|---------|
| 2025年4月 | FY2025 |
| 2025年9月 | FY2025 |
| 2025年12月 | FY2025 |
| 2026年1月 | FY2025 |
| 2026年3月 | FY2025 |
| 2026年4月 | FY2026 |

## 2. 四半期区分

| ID | 四半期 | 対象月（FY基準） | キー形式 | FY2025の具体月 |
|----|-------|----------------|---------|--------------|
| RULE-QTR-001 | **Q1** | 4月・5月・6月 | `FY2025-Q1` | 2025年4〜6月 |
| RULE-QTR-002 | **Q2** | 7月・8月・9月 | `FY2025-Q2` | 2025年7〜9月 |
| RULE-QTR-003 | **Q3** | 10月・11月・12月 | `FY2025-Q3` | 2025年10〜12月 |
| RULE-QTR-004 | **Q4** | 翌1月・翌2月・翌3月 | `FY2025-Q4` | 2026年1〜3月 |

## 3. KPI算出ルール

### 3.1 プロジェクトKPI

| ID | 指標 | 算出式 |
|----|-----|-------|
| RULE-KPI-001 | **四半期売上予算** | `projects.quarter_budgets["FY2025-Q1"] × 10000` （万円→円変換） |
| RULE-KPI-002 | **四半期コスト** | 当四半期の月（例: 4,5,6月）に属するアサインの `Σ(hours × cost_rate)` |
| RULE-KPI-003 | **四半期利益** | 四半期売上予算 − 四半期コスト |
| RULE-KPI-004 | **年間予算合計** | Q1〜Q4の四半期売上予算の合計 |
| RULE-KPI-005 | **年間コスト合計** | Q1〜Q4の四半期コストの合計 |
| RULE-KPI-006 | **年間利益** | 年間予算合計 − 年間コスト合計 |
| RULE-KPI-007 | **利益率** | `(年間利益 / 年間予算合計) × 100`（年間予算が0の場合は0%） |

### 3.2 要員KPI

| ID | 指標 | 算出式 |
|----|-----|-------|
| RULE-KPI-008 | **実績売上** | 選択年度のアサインコスト合計: `Σ(hours × cost_rate)`（当FYの月のみ） |
| RULE-KPI-009 | **年度予算** | `members.yearly_budgets["FY2025"] × 10000`（万円→円変換） |
| RULE-KPI-010 | **達成率** | `(実績売上 / 年度予算) × 100`（年度予算が0の場合は0%） |
| RULE-KPI-011 | **参加PJ数** | 当年度のアサインに含まれる重複なしのプロジェクト数 |
| RULE-KPI-012 | **総稼働時間** | 当年度の全アサインの時間合計 |

### 3.3 全社KPI（ダッシュボード）

| ID | 指標 | 算出式 |
|----|-----|-------|
| RULE-KPI-013 | **売上予算合計** | 全プロジェクトの年間予算合計 |
| RULE-KPI-014 | **コスト合計** | 全要員の年間コスト合計 |
| RULE-KPI-015 | **利益** | 売上予算合計 − コスト合計 |
| RULE-KPI-016 | **要員達成率** | `Σ(全要員の実績売上) / Σ(全要員の年度予算) × 100` |

## 4. 単位変換ルール

| ID | 段階 | 単位 | 説明 |
|----|-----|------|------|
| RULE-UNIT-001 | **入力** | 万円 | `quarter_budgets`、`yearly_budgets` はすべて万円で入力 |
| RULE-UNIT-002 | **内部計算** | 円 | 保存値 × 10,000 に変換して計算 |
| RULE-UNIT-003 | **表示** | 億/万/円（自動） | `fmtM()` 関数が金額に応じて自動選択 |

### 表示フォーマット例（`fmtM` 関数）

| 金額（円） | 表示形式 |
|-----------|---------|
| 1,000,000,000（10億） | `1.0億` |
| 100,000,000（1億） | `1.0億` |
| 50,000,000（5000万） | `¥5000万` |
| 10,000（1万） | `¥1万` |
| 5,000 | `¥5,000` |

## 5. 利用可能年度の決定ルール

画面上部の年度選択ボタンに表示する年度は、以下のデータから収集します。

- **[FY-004]** 全アサインレコードの月から算出した年度
- **[FY-005]** 全プロジェクトの `quarter_budgets` キーに含まれる年度
- **[FY-006]** 現在月（`CURRENT_MONTH`）が属する年度（必ず含める）

> **注意**: `CURRENT_MONTH = "2025-06"` は `src/lib/data.ts` にハードコードされています。
> ※推測（要確認）: 実運用では `new Date()` などを使った動的な日付取得への変更が必要か否かは未定です。

## 6. 達成率の色分けルール

達成率の値に応じて以下の色でビジュアル表現します。

| ID | 達成率 | 表示色 | 意味 |
|----|-------|--------|------|
| RULE-COLOR-001 | 100%以上 | 緑（Emerald） | 目標達成 |
| RULE-COLOR-002 | 70%以上100%未満 | 黄（Amber） | 目標に近づいている |
| RULE-COLOR-003 | 70%未満 | 赤（Red） | 目標から大きく乖離 |
