# パフォーマンス特性・制約

> **根拠ソース**: [src/app/page.tsx](../../src/app/page.tsx)（useMemo/useCallback）、[src/lib/storage.ts](../../src/lib/storage.ts)

---

## 1. データ取得の特性

> ID: PF-001

### 初期ロード

| ID | 項目 | 現在の実装 |
|----|-----|-----------|
| PF-002 | **取得方式** | 5テーブルを `Promise.all` で **並列** 取得（逐次取得より高速） |
| PF-003 | **取得範囲** | **全件取得**（ページネーション未実装） |
| PF-004 | **フィルタリング** | Supabase側ではなく、取得後にクライアント側でフィルタリング |

> ※推測（要確認）: データ件数が数千〜数万件規模に増加した場合、初期ロードの遅延が発生する可能性があります。ページネーションや部分取得への変更が必要になるかもしれません。

## 2. 計算処理の最適化（useMemo）

> ID: PF-010

頻繁に参照される計算値は `useMemo` でメモ化し、不要な再計算を防止しています。

| ID | メモ化変数 | 計算内容 | 再計算トリガー |
|----|----------|---------|-------------|
| PF-011 | `fyAllocs` | 選択年度に絞り込んだアサイン一覧 | `allocs`、`fyMos` の変化時 |
| PF-012 | `projectPL` | プロジェクト別四半期損益計算 | `projects`、`fyAllocs`、`selectedFY` の変化時 |
| PF-013 | `memberStats` | 要員別達成率・実績計算 | `members`、`fyAllocs`、`selectedFY` の変化時 |
| PF-014 | `availFYs` | 利用可能年度リスト | `allocs`、`projects` の変化時 |
| PF-015 | `fyMos` | 選択年度の全月リスト | `selectedFY` の変化時 |

## 3. 保存処理の性能特性

> ID: PF-020

### 全削除 → 全挿入方式

| ID | 項目 | 内容 |
|----|-----|------|
| PF-021 | **保存方式** | 差分更新ではなく、全削除 → 全挿入 |
| PF-022 | **保存タイミング** | State変更のたびに即座に実行 |
| PF-023 | **デバウンス** | 未実装 |

> ※推測（要確認）: ユーザーが連続して操作（例: フォームの各フィールドを素早く変更）した場合、Supabaseへのリクエストが高頻度で発生する可能性があります。デバウンス（例: 500ms待機後に保存）の導入が必要か検討が必要です。

### 保存リクエスト数の見積もり

- **[PF-024]** 1回の `saveData()` 呼び出しで最大10件のSupabaseリクエストが発生します。

```
削除: allocations, projects, members, roles, departments = 5リクエスト
挿入: departments, roles, members, projects, allocations = 最大5リクエスト（データがある場合）
合計: 最大10リクエスト/保存
```

## 4. グラフのレンダリング

> ID: PF-030

- **[PF-031]** **外部グラフライブラリを使用せず**、全グラフをCSS/SVGでゼロ依存実装しています。

| ID | グラフ | 実装方式 |
|----|-------|---------|
| PF-032 | `WaterfallChart`（COMP-007参照） | CSSの `height` プロパティで棒の高さを制御 |
| PF-033 | `QuarterBarChart`（COMP-006参照） | CSSの `height` プロパティで棒の高さを制御（3系列グループ） |
| PF-034 | `HBar`（COMP-007参照） | CSSの `width` プロパティでバーの幅を制御 |
| PF-035 | `AchievementRing`（COMP-008参照） | SVGの `strokeDasharray` / `strokeDashoffset` で円弧を制御 |

- **[PF-036]** **アニメーション**: Tailwind CSS の `transition-all duration-500` / `duration-700` クラスによるCSSトランジション

## 5. バンドルサイズ

> ID: PF-040

| ID | 項目 | 特性 |
|----|-----|------|
| PF-041 | ルーティング | 単一ページ（`/` のみ）でコード分割なし |
| PF-042 | 外部グラフライブラリ | なし（バンドルサイズへの影響なし） |
| PF-043 | アイコンライブラリ | `lucide-react`（tree-shakingで使用アイコンのみバンドル） |
| PF-044 | 主要ファイルサイズ | `page.tsx` は約400行の大型コンポーネント |

---

## 6. 制約・留意事項

> ID: PF-050

| ID | 制約 | 内容 |
|----|-----|------|
| PF-051 | **オフライン非対応** | Supabaseへの接続が必要。オフライン時は動作しない |
| PF-052 | **同時編集非対応** | 複数ユーザーや複数タブからの同時操作は上書きが発生する可能性がある |
| PF-053 | **大量データ** | 全件取得のため、数万件超のデータでは遅延が発生する可能性がある |
| PF-054 | **ブラウザ依存** | `localStorage`、`FileReader`、`URL.createObjectURL` 等のブラウザAPIを使用 |
